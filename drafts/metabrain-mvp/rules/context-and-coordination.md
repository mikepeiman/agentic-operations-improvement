# Context and coordination

## Route context

Start with:

1. the repository constitution;
2. the current user request or compact task capsule;
3. one to three routed current sources.

Search by heading, symbol, exact term, relationship, or bounded path. Read
archive material only for a named provenance question. Confirm structural-index
and search results in current defining evidence.

## Maintain a task capsule

For long work, keep a compact record of:

- objective;
- current state;
- governing sources;
- evidence and decisions;
- acceptance criteria;
- owned files and processes;
- verification performed;
- next concrete action.

Checkpoint and continue from the capsule when transcript size reduces
performance.

## Delegate narrowly

Delegate only an independent bounded question. Provide named files or sources,
the precise output, acceptance criteria, and write ownership. Do not pass a
large parent transcript when a compact capsule is sufficient.

Use bounded parallelism. Do not fan out a repository sweep without a stated
purpose. Enforce configured input-token, cost-per-call, cost-per-task, model,
and concurrency limits. Do not silently change billing or model policy.

**Compliance:** every loaded source and delegated task has a task-relevant
purpose, and configured resource limits remain enforced.
