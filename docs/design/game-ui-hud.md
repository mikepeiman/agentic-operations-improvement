# Game UI / HUD Design Guidance

Use for HUDs, combat UI, match setup, inventories, loadouts, shops, maps, scoreboards, skill trees, settings, game menus, diegetic interfaces, and game UX flows.

## Primary reference galleries

- **Game UI Database** — https://www.gameuidatabase.com/  
  Huge searchable database of game UI across genres, platforms, screens, HUD types, inventories, menus, maps, etc.
- **Interface In Game** — https://interfaceingame.com/  
  Extensive screenshots and videos searchable by genre, theme, and interface element.
- **HUDS+GUIS** — https://www.hudsandguis.com/  
  Exceptional reference for HUDs, futuristic UI, cinematic interfaces, displays, targeting systems, and visual language.
- **Game Accessibility Guidelines** — https://gameaccessibilityguidelines.com/  
  Useful counterweight to purely visual inspiration: readability, input, feedback, subtitles, contrast, timing, and accessibility.
- **Can I Play That?** — https://caniplaythat.com/  
  Practical accessibility analysis of real games and game interfaces.

## Guidance

Start by researching **the same game genre and the same UI problem**. An inventory screen, artillery HUD, card battler, FPS reticle, and strategy control room solve very different problems.

Study several references and separate:
- information architecture,
- moment-to-moment readability,
- input/action priority,
- visual hierarchy,
- feedback and state changes,
- game-world aesthetic.

HUD design should support play first. Keep frequently needed information glanceable and avoid covering the playfield without purpose.

Design for actual play states: normal, aiming, targeting, damaged, cooldown, unavailable action, alerts, selection, multiplayer status, and transitions.

Prefer established game conventions when they reduce learning cost, but use the game's visual identity aggressively where it does not hurt clarity.

Treat animation, sound, color, scale, and motion as functional feedback—not merely decoration.

Test against the real gameplay background. A beautiful HUD on a blank canvas can fail completely over terrain, VFX, enemies, particles, and motion.

**Working principle:** borrow interaction wisdom from successful games in the same genre, then build a visual language that belongs specifically to this game.
