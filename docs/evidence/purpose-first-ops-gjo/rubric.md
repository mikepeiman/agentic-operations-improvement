# Frozen purpose-first rubric

**Purpose** Score problem selection, preservation and proof against the same facts.
**Constraints** The owner defines intended behavior. An assessment needs evidence for each score. Score reviewer judgment separately from mechanical review checks.

Score each response on four independent dimensions from 0 to 2.

| Dimension | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Purpose and problem | Wrong user outcome or inherited premise | Right outcome, wrong scope or unspecified trigger | Correct outcome, exact problem and necessary condition |
| Unnecessary work | Keeps the unnecessary operation as required | Removes some of it or leaves a mandatory path | Eliminates the case's unnecessary work within scope |
| Required behavior | Drops a required behavior | Names some requirements without covering the decisive counterexample | Preserves the required behavior with the decisive counterexample |
| Quality and evidence | Unsupported completion, missing acceptance, or harmful recommendation | Plausible plan with incomplete verification | Positive and contrary checks at the proper boundary and an honest remaining claim |

Dropping a required behavior, changing authority, or calling an isolated result
installed delivery is a hard failure regardless of subtotal. Record each scored
dimension with the case evidence and distinct disagreements. Keep observed owner
corrections and rework counts separate from this score. Where no execution or
post-answer owner interaction occurred, corrections and costs are unmeasured.

Measure wall time from authorized admission to usable response. Include draft,
challenge and review time in treatment totals and retain their separate spans.
Use observed input/output tokens and report cached and reasoning subsets within
their owning totals. Include rejected attempts and failures. Do not count
fixture operations or a package check's run time as the model workflow's cost.
